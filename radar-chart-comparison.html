🤖 Automation Level Comparison — Radar Charts

4 automation levels × 8 criteria · Tradeoff visualization for non-technical audiences

Chart.js ★ RECOMMENDED

v4.5.1 · 200KB CDN · MIT License

✅ Pros

  • 30 lines of JS — simplest API for radar charts
  • Interactive tooltips out of the box (hover → see exact values)
  • Responsive — resizes cleanly on mobile
  • Legend toggles datasets on/off (click to compare subsets)
  • Canvas-based = crisp on retina screens

⚠️ Cons

  • Less animation polish than ApexCharts
  • Fill transparency can muddy with 4 overlapping datasets
  • Custom axis labels require plugin workarounds

ApexCharts GOOD ALTERNATIVE

v4.4.0 · 150KB CDN · MIT License

✅ Pros

  • Prettiest out-of-the-box animations
  • Built-in data labels on each point (no plugin needed)
  • Dark theme is excellent — looks professional immediately
  • Built-in export to PNG/SVG
  • Legend with click-to-hide is very polished

⚠️ Cons

  • Slightly more config boilerplate than Chart.js
  • 4 filled datasets can look cluttered (mitigate with opacity)
  • Larger total bundle if already using Chart.js elsewhere

D3.js ADVANCED

v7 · 100KB CDN · ISC License

✅ Pros

  • Full control over every pixel — unlimited customization
  • Smallest core library (others wrap D3 internally)
  • Can add custom annotations, animations, interactions
  • Best for unique, branded visualizations

⚠️ Cons

  • 100+ lines of boilerplate for a basic radar chart
  • No built-in radar chart — you build the SVG from scratch
  • No tooltips, legends, or interactivity without manual code
  • Steepest learning curve by far

📋 Verdict for Non-Technical Audiences

Winner: Chart.js for this use case.
It hits the sweet spot: dead-simple code, interactive tooltips that let non-technical users hover to see exact scores, and clickable legends to isolate individual automation levels. The 4 overlapping fills with 20% opacity create a clear visual hierarchy where tradeoffs are immediately visible as area shapes.

Runner-up: ApexCharts if you want the chart to look like it came from a design agency. Better default aesthetics, but slightly more config.

Skip D3.js unless you need a one-off custom visualization with unique interactions. The ROI isn't there for a comparison chart.

Key insight for tradeoff visibility: use fill: true with low opacity (0.1–0.2) so overlapping areas blend visually. The shape of each area tells the story — a lopsided shape = tradeoff, a balanced shape = well-rounded. Users don't need to read numbers.
